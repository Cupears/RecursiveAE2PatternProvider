I fixed the recursive off toggle when re-encoding, guarded optional wireless-terminal support, and added orange ingredient explanations to successful crafting plans. I also added troubleshooting guidance and a crafting issue form.

I use Minecraft 26.1.2, NeoForge 26.1.2.109 or a newer 26.1.2 build, Java 25, and Applied Energistics 2.

To update, I close Minecraft and stop my server, remove the older Otter JAR (and the original Recursive AE2 Pattern Provider JAR if installed), and put `otter-patterns-1.1.2.jar` in both mods folders. This fork shares the original mod ID, so only one copy can be installed.
