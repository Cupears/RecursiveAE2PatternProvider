I added a recipe-tree editor on `feature/recipe-tree-editor`. I can hold a recursive pattern, right-click in air, inspect recipe alternatives, and disable unwanted generated routes for that pattern. The editor uses orange accents, supports pan/zoom and expandable branches, and saves exclusions on the encoded item.

After saving, I reinsert the pattern in its provider and request a new craft. Other providers and manual patterns can still offer routes through AE2's shared network. The bounded preview shows example crafting ingredients rather than ME stock or a selected crafting plan.

This branch build is `otter-patterns-1.2.0-beta.1.jar` for Minecraft 26.1.2, NeoForge 26.1.2.109 or a newer 26.1.2 build, Java 25, and Applied Energistics 2. I keep only one Otter/Recursive AE2 Pattern Provider JAR in each mods folder.
